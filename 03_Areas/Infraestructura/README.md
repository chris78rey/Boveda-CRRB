# Infraestructura informática

Inventario de equipos, máquinas virtuales, redes, servicios y dependencias.

> [!warning]
> No guardar contraseñas, tokens, claves privadas ni cadenas de conexión con secretos.
> Registrar únicamente una referencia a KeePassXC, Bitwarden u otro gestor seguro.

## Panel

Abrir [[08_Dashboards/Dashboard de infraestructura]].

## Convenciones

- Un equipo puede tener muchas credenciales; cada credencial es una nota separada.
- En `equipo` se utiliza un enlace a la nota del activo.
- Usar estados `activo`, `mantenimiento`, `retirado` o `propuesto`.
- Usar ambientes `produccion`, `pruebas`, `desarrollo` o `laboratorio`.
