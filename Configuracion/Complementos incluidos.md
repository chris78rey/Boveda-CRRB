# Complementos incluidos

Los complementos se encuentran instalados en `.obsidian/plugins` y habilitados
mediante `.obsidian/community-plugins.json`.

| Complemento | Identificador | Versión incluida |
|---|---|---:|
| Advanced Tables | `table-editor-obsidian` | 0.23.2 |
| Calendar | `calendar` | 1.5.10 |
| Dataview | `dataview` | 0.5.68 |
| Excalidraw | `obsidian-excalidraw-plugin` | 2.26.4 |
| Kanban | `obsidian-kanban` | 2.0.51 |
| Map View | `obsidian-map-view` | 6.1.4 |
| Pandoc Plugin | `obsidian-pandoc` | 0.4.1 |
| QuickAdd | `quickadd` | 2.23.0 |
| Recent Files | `recent-files-obsidian` | 1.7.10 |
| Tasks | `obsidian-tasks-plugin` | 8.4.0 |
| Templater | `templater-obsidian` | 2.25.0 |
| YTranscript | `ytranscript` | 1.4.0 |

## Consideraciones

- QuickAdd contiene las cinco capturas originales y doce acciones nuevas.
- Templater utiliza la carpeta `09_Plantillas`.
- Pandoc Plugin está incluido, pero la exportación requiere que el programa
  Pandoc esté instalado en el sistema operativo.
- YTranscript necesita conexión a Internet al solicitar una transcripción.
- Obsidian puede solicitar confirmación antes de habilitar complementos
  comunitarios al abrir la bóveda por primera vez.

Los ejecutables se obtuvieron de las publicaciones oficiales de cada proyecto
registrado en el catálogo comunitario de Obsidian.
