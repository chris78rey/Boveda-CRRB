# Transformar a Prompt

## Prompt
"**Analiza exhaustivamente el contenido de `[ {{TEMA}} ]` y, con base en la información contenida, genera un nuevo prompt. Este prompt debe ser:**

* **Super profesional:** Emplea un lenguaje formal, técnico y preciso, adecuado para un contexto empresarial o académico de alto nivel.
* **Integral:** Sintetiza y refleja fielmente todas las ideas, datos y matices presentes en el texto original, sin omitir información relevante.
* **Coherente y lógico:** Presenta una estructura clara, con argumentos bien fundamentados y una progresión de ideas fluida.
* **Conciso pero completo:** Evita la redundancia, pero asegura que se aborden todos los puntos clave de manera exhaustiva.
* **Orientado a la acción (si aplica):** Si el contenido de `[ {{TEMA}} ]` implica pasos, decisiones o directrices, el prompt debe reflejar esta orientación de manera explícita y actionable.

**Tu objetivo es crear un prompt que, al ser utilizado, evoque respuestas de la más alta calidad, reflejando la complejidad y profundidad del texto original.**"
