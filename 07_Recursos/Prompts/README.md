# Biblioteca de prompts

Guarda aquí prompts reutilizables. Usa placeholders con esta sintaxis:

```text
Servidor: {{servidor}}
Ambiente: {{ambiente|produccion}}
Error: {{error}}
```

Desde QuickAdd → `CRRB - Prompts` → `Copiar prompt`, se selecciona el prompt,
se completan sus variables y el resultado final se copia al portapapeles.

Las copias completadas son opcionales y se guardan en `Historial`.
